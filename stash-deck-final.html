01 — The Problem

I read a lot.
I couldn't find anything.

01
Scattered everywhere
Substack articles in a personal WhatsApp chat. YouTube links in Chrome bookmarks. Case studies in a forgotten Notion doc. No single place.
02
Saved, never returned to
New Yorker pieces. Newsletters. Videos people shared at work. Saved with every intention. Never went back. Just accumulating.
03
Back to Google every time
When I actually needed something, I'd search from scratch — trying to reconstruct it from whatever I half-remembered. The saving was pointless.

"I knew this was a solvable problem. I just wanted to solve it for me."

02 — The Insight

The hard problem isn't saving.
It's recall.

What existing tools do
—Optimise for the save moment
—Require manual organisation
—Never resurface what you've read
—Built before LLMs changed what's possible
What I wanted
—Save in one click, organise automatically
—Find things by just asking a question
—Works across browser and phone
—Mine — data I own, no subscription

03 — The Approach

"Built for saving.
Actually works for remembering."

Every save is automatically summarised, tagged, and categorised. When you need something, you ask for it in plain English — and it searches only what you've actually read.

Old workflow

→

04 — What's Built

Four things that actually work today.

01 — Capture
Save in one click
Chrome extension captures any article, YouTube video, or webpage instantly. Click the icon, done. No folders, no manual tags, zero friction.
Chrome Extension · Live
02 — Organise
AI does the work
Gemini reads every save and generates a summary, tags, and category automatically. Organised before it even hits your library — without you touching it.
Gemini API · Live
03 — Recall
Ask, don't search
Type keywords or ask in plain English — "what did I save about attention spans?" Semantic search over your personal library only. Answers from what you've read.
pgvector · Live
04 — Mobile
Save from your phone too
The PWA share target didn't work. So I used the iOS Shortcuts app to build a workaround — tap Share, run the shortcut, saved. Not elegant, but it works.
iOS Shortcuts · Live

05 — Under the Hood

The stack that made it possible in a day

Frontend
⚛️
React + Vite
Deployed on Vercel. Warm cream UI, terracotta accents. Minimal by design.
Backend
🐍
Python / FastAPI
Deployed on Railway. Handles ingestion, AI calls, and semantic search.
Database
🗄️
PostgreSQL + pgvector
Hosted on Neon. Vector embeddings for semantic search alongside structured data.
AI
🤖
Gemini API
Summarisation, tagging, category assignment, and conversational Q&A. Free tier.
Extension
🔖
Chrome Extension
One-click save from any page. Sends URL to the backend. No complex manifest needed.
Mobile
📱
iOS Shortcuts
PWA share target didn't work. Built a Shortcuts workaround instead. Hacky but effective.

07 — The Real Point
